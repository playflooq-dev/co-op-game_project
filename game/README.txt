TREASURE HUNT - game prototype
==============================

HOW TO OPEN
Double-click index.html. It opens in your web browser.
No installation and no internet connection are needed.
Use an up-to-date Chrome, Edge, Firefox or Safari.

THE SCENES
index.html    Chapter One, "Home Alone": the brother and sister are locked in the house
              and must find the spare key. Next comes the city (Chapter Two, not made yet).
forest.html   The Forest Trail scene (the first art test; not linked from Chapter One for now).

CONTROLS (two players on one keyboard)
Sister:   A / D walk     W use, go upstairs     S go downstairs, look into things
Brother:  Left / Right walk     Up use, go upstairs     Down go downstairs, crawl in
Pressing W or Up with nothing nearby makes that character cheer.
On a phone or tablet, on-screen buttons appear instead.

HOW CHAPTER ONE WORKS (spoilers)
The sister is tall: only she can reach Dad's locked box on top of the study bookcase.
The brother is small: only he fits in the dark cupboard under the stairs, where he pulls
the light cord and finds the box code chalked inside. He tells her the code, she opens the box, and the
spare key opens the front door. The code changes every game.

WHAT IS IN THE FOLDER
index.html, forest.html   the two scenes; open index.html to start
assets/                   all the artwork as separate image files; assets/house/ is the house.
                          assets/README.md explains how to replace any of them.
js/                       the code that runs the scenes
tools/                    developer tools used to create the artwork and test the game;
                          not needed to play
