Export assets

Paints one world's scenery with its original drawing code (worlds/<world>/generate.js) and saves the PNGs into worlds/<world>/assets/, together with a fresh manifest.js. This overwrites the PNG files that are there. Open it through python tools/dev_server.py, not by double-clicking, with one of:

  • ?world=forest
  • ?world=house
  • ?world=city
  • ?world=characters (only the reference pictures in shared/characters/)
